# components/ui

shadcn/ui primitives, generated by the CLI: `pnpm dlx shadcn@latest add <name>`.

## Belongs here

CLI output, added one component at a time as something actually needs it — not a bulk install.

## Doesn't belong here

Hand-written components, and any domain knowledge. These files must stay generic enough that
re-adding them from the registry is a non-event.

## Gotchas

- **Hand-edits must survive a re-add.** There is one: the AlertDialog overlay is bumped to
  `bg-black/60` because the default `bg-black/10` is invisible on a dark background. Re-adding
  `alert-dialog` silently reverts it.
- This is the only place in the app allowed to use `dark:` variants — they are part of the
  generated output. App code never writes them; the app is dark-only by design.
